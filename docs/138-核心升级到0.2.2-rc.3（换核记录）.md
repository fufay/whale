### 新包：`@deepseek-ai/dsh-deepseek-chat-import@0.2.2-rc.3`

- 定位：`Import DeepSeek chat exports as stored Sessions in a chosen Workspace`
  （把 DeepSeek 导出的聊天记录导入成所选 workspace 里的 stored session；带侧栏入口、owner-only 上传路由、limits remote）。
- 结构：host `lib/index.js` 58.8 KB + 浏览器 `lib/client.js` 41.4 KB + 8 语言 locale；
  依赖仅 zod / fflate / brand / schemastery / typert-protocol ⇒ **纯 JS，零原生依赖**。
- 默认**不启用**：它自己的 `cordis.patch.yml` 注释写明 "Shipped profiles do not include this layer"，
  上游把它放进可选/实验 bundle 列表 ⇒ 端侧只会在「插件 → 更多」里多出一个带实验标的可选项。
  **本轮没有把它加进 Whale profile**（要不要开是产品决定，见 DECISIONS 待记）。

## 4. 坑（本轮新增）

1. **`pack-core` 直接跑 npm install 会 `exit=null`**：`spawnSync` 起 node24 的 npm 在设备上被信号杀掉
   （无 stderr）。绕法：先手动 `npm install`（4 分钟 / 668 包），再 `pack-core --skip-install` 继续。
   手动安装请用 **node24 的 npm**（`PATH=…/node@24/bin:$PATH`；本机 `npm` 垫片是安装队列假壳）。
2. **`binary-sign-tool` 仍缺**：`.node/.so` 自签名步骤跳过（与 rc.2 同），树内已有 `.codesign` 随 npm 包不带来
   —— 本轮 `assert-rg-selfsigned` 与 `check-native-closure` 均通过，且设备内核树功能正常；如后续要重新自签，
   需补 `binary-sign-tool`（见 docs/130）。
3. 工作树条目数从 57,885 增到 58,474（新包 + 新装依赖的嵌套布局差异），体积仅 +1.3 MB。
