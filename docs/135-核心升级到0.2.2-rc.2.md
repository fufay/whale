## 7. rg 可用性（v1.1.8 修复）

rc.2 把 rg 执行迁到 `@deepseek-ai/dsh-util-ripgrep`（`resolveRgPath()` → `import('@vscode/ripgrep').rgPath`），
rc.1 那套 34 KB 的 find/grep 降级整段失效。**v1.1.8 改用构建期自签名**（方案 b）：

- `pack-core` 的 `ensureRipgrepPlatformPackage()` 现在会用 `ohos-selfsign sign` 给 `@vscode/ripgrep-linux-arm64` 的
  `bin/rg` 追加 `.codesign`，`verify` 通过后再注入到 **`@vscode/ripgrep-openharmony-arm64`**（`@vscode/ripgrep`
  按 `process.platform` 拼包名，端侧是 `openharmony`）；同时清掉旧 `linux-arm64` 目录，避免多带一份未签名 rg。
- 实测：从最终 core zip 里取出 rg → `ohos-selfsign verify` **codesign=yes / selfsign=yes / signature_match=yes**，
  放进应用沙箱直接执行输出 `ripgrep 15.0.0` ⇒ 端侧 `grep`/`glob` 走真 rg。
- `hostcore/app/main.js` 的 rg 真身路径与 PATH wrapper 同步改到新平台包名。
- 门禁：新增 `tools/assert-rg-selfsigned.mjs`（13 项：签名/路径/解析模板/无旧降级/无残留），
  删除已退役的 `tools/assert-fs-search-fallback.mjs`；`assert-exec-fix` 的 rg 路径断言同步。
