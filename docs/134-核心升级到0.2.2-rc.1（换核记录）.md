## 2. 换核前修的两处（工具层）

### 2.1 pack-core：fs-local 补丁改为双形状（`tools/pack-core.mjs`）

上游把 `writeFileAtomic` 的 `createIfAbsent` **形参**改成了 `options` 对象
（`options.createIfAbsent` / `displayPath` / `existingDestination`），旧锚点第一次 dry-run 直接 `die()`。
现 `patchFsLocalLink()` **两种形状都认**（先 `options` 对象形态、再旧形参形态），都不中才 `die()`，
日志会打印命中的是哪种形态。语义不变：link 类错误且目标确实不存在 ⇒ rename 发布（鸿蒙禁硬链接）。

### 2.2 protocol-contract：补 npm 构建产物的兜底提取（`tools/protocol-contract.mjs`）

上游把 typert 描述符从「源码里的 `{ id, service, namespace, method }` 字面量」改成**构建期
序列化的描述符表**（`dsh-api-remotes/lib/client.js`，键 `"ns/method"`），旧正则一条都匹配不到 ⇒
本机跑会**静默报 0 endpoint**（假绿，即 `docs/128` 里登记的那条 BLOCKED 的根因）。
新增兜底：源码形态为 0 时，按描述符表提取（含 `wire` 线上名、条目顶层 `mode: "stream"`、
`cancellation`、`sourceLocation`、声明包），实测提取 **150/150** 条；
`gen-compat-endpoints` / `compat-drift` 无需改动即可复用。

## 3. 协议基线

- 重生成 `dshcompat/src/main/ets/Endpoints.ets`：**150 端点**（流式 16），`UPSTREAM_IDENTITY.corePackage = 0.2.2-rc.1`。
- `CompatIndex.SUPPORTED_VERSIONS` 首位加入 `0.2.2-rc.1`，矩阵历史补记本轮漂移（+16/−9 相对 alpha.1 基线；相对 alpha.2 仅 schedule 域）。
- 漂移门禁：`DSH_CONTRACTS=contracts-0.2.2-rc.1.json node tools/compat-drift.mjs` → **exit 0「无漂移」**（期望 150 / 基线 150）。
- **负测试**：同一份新基线上用 alpha.2 契约跑 → **exit 1**（门禁真会红，不是假门）。
- 影响面：Whale 自有代码不调用 schedule 端点，故本次**零调用代码改动**。
